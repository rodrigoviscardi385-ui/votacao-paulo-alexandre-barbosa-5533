# 🗳️ Painel de Votação Oficial - Deputado Federal Paulo Alexandre Barbosa (5533)

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Online%20%26%20Responsivo-brightgreen?style=for-the-badge&logo=github)](https://rodrigoviscardi385-ui.github.io/votacao-paulo-alexandre-barbosa-5533/)
[![Fonte dos Dados](https://img.shields.io/badge/Dados-TSE%20Oficial-blue?style=for-the-badge)](https://resultados.tse.jus.br)

Painel analítico e territorial interativo com a apuração oficial de todos os **645 municípios do Estado de São Paulo** para a candidatura do **Deputado Federal Paulo Alexandre Barbosa (5533)**, com foco aprofundado nas 4 principais Regiões Metropolitanas de SP.
