# Painel de Votação Oficial - Deputado Federal Paulo Alexandre Barbosa (5533)

Dashboard interativo oficial com a apuração de todos os **645 municípios do Estado de São Paulo** e detalhamento analítico das 4 Regiões Metropolitanas:
- **Região Metropolitana da Baixada Santista (RMBS)**
- **Região Metropolitana de São Paulo (Grande SP)**
- **Região Metropolitana do Vale do Paraíba e Litoral Norte (SJC)**
- **Região Metropolitana de Campinas (RMC)**

## 📊 Acesso Online
O painel pode ser acessado diretamente pelo GitHub Pages deste repositório.

## 📁 Arquivos Inclusos
- `index.html`: Dashboard interativo com gráficos e filtros
- `Relatorio_Executivo_Paulo_Alexandre_Barbosa_5533.pdf`: Relatório em PDF A4 executivo
- `Dashboard_Painel_Paulo_Alexandre_Barbosa_5533.pdf`: Versão completa do painel em PDF
- `votacao_paulo_alexandre_barbosa_5533_sp.csv`: Base de dados dos 645 municípios
- `relatorio_regioes_metropolitanas_5533.csv`: Dados das 4 Regiões Metropolitanas
- `scraper_paulo_alexandre_5533.py`: Código-fonte da extração oficial junto ao TSE
